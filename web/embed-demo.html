Embed demo

Your website, with the SmartUp assistant

This page stands in for a page of smartupacademy.org. The chat bubble in the corner is the embeddable widget — the same code that renders the full-page chat.

How to embed

Add one script tag before </body> and point data-api-base at the server that runs the API:

<script src="https://YOUR-API-HOST/widget/widget.js"
        data-api-base="https://YOUR-API-HOST"
        data-title="SmartUp Assistant"
        data-lang="auto"
        data-theme="light"
        data-primary="#2b4acb" defer></script>
data-themelight, dark or auto (follows the visitor's OS) data-primarythe brand colour; every other colour is a CSS variable on .su-widget data-suggestionsa JSON list of questions offered before the first message data-positionright or left

Set CORS_ORIGINS=https://www.smartupacademy.org in the API's .env so only your site may call it. Then open the bubble (bottom right) and ask, for example, What does the course say about pricing? or מה שיעורי הבית של הרצאה 5?
